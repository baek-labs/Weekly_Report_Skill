# 주간업무보고 취합 스킬

팀별 주간업무보고 메일(네이버웍스)과 주간 매출 엑셀을 모아, 정해진 양식의 사업부 취합본을 만들어 **실행한 사람 본인에게만** 메일로 보낸다. 사업부장이 받은 메일을 확인·수정한 뒤 직접 전달한다.

## 구성

```
.claude-plugin/marketplace.json        배포용 마켓플레이스 목록
plugins/weekly-report/
  .claude-plugin/plugin.json           플러그인 정보
  skills/weekly-report/
    SKILL.md                           처리 순서와 원칙
    template.html                      취합본 본문 양식 (메일용 HTML)
```

## 사용 방법

1. Claude에서 "11월 2주차 주간보고 정리해줘"라고 요청한다.
2. 주간 매출 엑셀을 대화창에 끌어다 놓는다(없으면 "없음").
3. 본인 메일함에 `[주간보고 취합본] {사업부} …` 메일이 오면 확인·수정 후 전달한다.

## 필요한 환경

- Claude 웍스 커넥터 연결 (서버 주소 `https://mcp.worksmobile.com/mcp`, Team·Enterprise 요금제는 조직 소유자가 조직 설정 → 커넥터에 먼저 등록)
- 엑셀을 읽기 위한 코드 실행 기능

## 팀 보고 작성 안내 (사업부장 지시 사항)

- 제목: `[주간업무보고] 26년 11월 2주차_팀명`
- 핵심 수치와 내용은 메일 본문에 글이나 표로 쓰고, 첨부는 참고용으로만 붙인다.

## 세팅일 확인 항목

- [ ] 웍스 커넥터 연결, 메일·캘린더 기능 사용 가능 여부(웍스 관리자 설정)
- [ ] 이 저장소로 스킬 설치, 수정본 업데이트 반영 여부
- [ ] 팀 보고 10통 이상을 한 통씩 처리할 때 한도에 걸리지 않는지
- [ ] 대화창에 넣은 주간 매출 엑셀로 매출 현황이 채워지는지
- [ ] 본인에게 온 취합본 메일에서 표·막대가 깨지지 않는지, 발송 전 확인 창이 뜨는지
